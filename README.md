# מערכת חימום למפעל שוקולד — קונספט

מצגת אינטראקטיבית בעברית של מערכת מים חמים חשמלית לחימום מעטפות צנרת ומכלים קיימים.

**קונספט בלבד — לא תכנון לביצוע.** לא נבחרו הספקים, מידות, ספיקות או ערכי כיוון. נדרשים נתוני אתר, מסמכי ציוד, חישובים ואישור מהנדס לפני ביצוע.

המצגת ב־[index.html](index.html) כוללת ארבע לשוניות: חדר הדוד בתלת־ממד, תרשים המערכת, רכיבים וספקים, ולוח טכנאי בהדגמה. בתצוגת התלת־ממד: ניווט בעכבר, שם קצר בריחוף וכרטיס יחיד בלחיצה; אפשר גם לאתר רכיב לפי תג או שם.

הצרכנים שמחוץ לחדר מיוצגים בשישה זוגות חיבור בלבד. המודל אינו מתאר מפעל מסוים. שמות הספקים וקישורים ציבוריים נשמרו כאפשרויות לבדיקה, ללא אישור התאמה, מחיר, מלאי או התחייבות לשירות.

האתר סטטי וללא תלות בחבילות חיצוניות. יש להגיש את התיקייה באמצעות שרת HTTP מקומי או אירוח סטטי. אין חיבור לבקר, לציוד מפעל או לחשבון חיצוני ואין שליחת פקודות פיזיות.

לוח הטכנאי הציבורי נפתח בדוגמת עבודה תקינה, עם ארבעה תרחישי הצגה זמינים לכל צופה: עבודה תקינה, תקלה במשאבה A, התחממות יתר וחוסר מים. לחיצה טוענת הדגמה חדשה; היא אינה איפוס תקלה. לחצים וטמפרטורות מסומנים כ״דוגמה״ ואינם מדידות אתר, ערכי כיוון או ספי הגנה. פקודה ומשוב נשארים נפרדים; בדיקת קלטים מתקדמת שומרת על הרשאות ועל הפרדת אישור ראייה מאיפוס.
